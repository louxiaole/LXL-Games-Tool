# LXL 游戏工具箱

把常用的游戏工具集中到一个窗口里：**装、更新、启动，都点一下就好。**

不用再记一堆官网地址，也不用到处找安装包。工具箱会自动看你电脑上装了什么，没装的帮你装，装旧的帮你更新，装好的直接启动。

---

## 一、它能帮你做什么

| 功能 | 说明 |
| --- | --- |
| 一个窗口找齐工具 | 11 个常用工具，按 5 个专区分类，支持搜索和分类筛选 |
| 自动识别已安装 | 扫描本机常见目录（含其它磁盘），认出你装过的软件并标记版本 |
| 一键安装 | 能直连官方的软件直接在工具箱里下载安装；不能的帮你打开官网 |
| 版本检测 | 本地比官方旧时标「旧版」，并给出独立的「更新」按钮（不强制更新） |
| 后台下载 | 下载在后台跑，切到别的页面也不中断，进度在「下载中心」实时看 |
| 卸载 / 迁移 | 每个工具可一键卸载；樱花内网穿透还支持把安装目录整体搬到别的盘 |
| 桌面快捷方式 | 设置里一键在桌面创建启动图标 |
| 换外观 | 10 套主题、浅色/深色、8 种主题色、8 张壁纸，也支持自定义背景图 |
| 工具箱自身更新 | 「更新日志」页可查看历史版本，并在线更新工具箱 |

## 二、专区和收录的工具

**小乐自制工具**（自己开发，支持自动更新）

- **Rust Solo Tools** — Rust 开服管理，单机开服、插件配置、服务器状态
- **小乐商店百科** — 商店/物品百科查询，内置元素、材料、技能数据

**游戏修改器专区**（第三方）

- **GameBuff** — 7000+ 款单机游戏修改器，一键启用修改项

- **WeMod** — 自动识别游戏，社区修改项随时开关
- **Cheat Engine** — 开源内存修改调试工具，适合进阶玩家自己搜数值

**联机工具专区**

- **樱花内网穿透（SakuraFrp）** — 把本地开放到公网，好友不用公网 IP 也能连进你的存档或服务器

**磁盘工具专区**（不重装系统就能调整分区）

- **分区助手** — 合并、拆分、扩容分区，把空余空间划给 C 盘
- **DiskGenius** — 分区调整、无损扩容、坏道检测、数据恢复

**游戏辅助专区**

- **游戏加加** — 实时显示帧率、CPU/显卡占用与温度，定位掉帧卡顿

## 三、卡片上的按钮怎么看

- **安装 / 下载并安装** — 本机没有这个软件。能直连的会自动下载并打开安装向导
- **前往官网下载** — 官方安装包需要登录或不能直链，点开会打开官网下载页
- **启动** — 已装好，直接打开（有新版也不会被强制更新）
- **更新到 x.x** — 只有检测到本机是旧版时才出现，是额外按钮，点它才会下载新版
- **详情** — 版本、安装位置、更新说明，还能「选择本地程序」「打开安装目录」
- **卸载** — 先关掉软件再点，工具箱会把安装目录一起清理
- **扫描本地 / 一键更新** — 顶部两个按钮：重新扫描本机安装情况；把所有旧版一次性加入后台下载

## 四、几个常见问题

**问：明明装了，为什么显示「未安装」？**
先点顶部的「扫描本地」；还认不出来就进「详情 → 选择本地程序」，手动指定主程序，之后会一直记住。

**问：为什么标「旧版」？**
工具箱读到的官方版本比本机的新。点卡片上的「更新到 x.x」就行，只想继续用旧版就点「启动」，不受影响。

**问：下载跑哪去了？**
左侧「下载中心」。第三方软件的安装包下完会自动拉起安装向导；自制工具会直接解压安装并刷新状态。那里还能取消、重新运行安装程序、清理已完成任务。

**问：文件都存在哪？**
全部跟着工具箱自己的目录走，不往 C 盘写：配置和日志在 `Data`，自制工具在 `tools`，第三方软件建议装到 `apps`。

**问：需要先装什么？**
Windows 10 / 11（64 位），以及 **.NET 8 桌面运行时**（Desktop Runtime）。

## 五、关于

- 本工具箱只提供下载入口、安装与启动管理，第三方软件的版权归各自官方所有。
- 修改器请在单机 / 离线游戏中使用，不要在联机或带反作弊的环境开启。
- 分区、扩容类操作有数据风险，动手前请先备份重要数据。

## 六、开发者：发版与在线更新

工具箱自带在线更新，客户端会读取本仓库的 **Latest Release**：

1. 修改 `LXLGameToolbox/Core/AppState.cs` 中的 `VersionText`
2. 用 `dotnet publish -c Release -r win-x64 --self-contained false` 输出发布文件
3. 只把 `LXLGameToolbox.exe`、`.dll`、`.deps.json`、`.runtimeconfig.json` 四个文件打成 **扁平结构的 zip**（不能套文件夹）
4. 建 tag（如 `v1.1.1`）并推送
5. 在 Releases 页发布正式版本（不要勾 pre-release），把 zip 作为附件上传，文件名带 `win` 会被优先选中

更新时客户端会下载该 zip，退出后自动替换文件并重新启动。
